# Atana SA Delivery Framework v1.0

Primary: South African stages 1–6.
Secondary labels: RIBA / ISO 19650 via project Display Mode (SA / RIBA / Both).
Tasks do not change when labels change.

## Governance
- DTL = Accountable (A)
- IM = Responsible (R) for Information Management activities
- PDM = Responsible for design / package orchestration

## WBS
Stage → Governance tasks (DTL / PDM / IM) → Production package → Deliverables → Review → QA → Submission → ZZ gate

## ZZ is gates, not a role
ZZ-001 Stage Start … ZZ-010 Closeout

## Visibility
Active role: editable.
Other DTL / PDM / IM tasks: visible, grey, read-only.

## Catalogues
DTL.01–10, PDM.01–06, IM.01–08 as implemented in app.html (ATN_FW).
