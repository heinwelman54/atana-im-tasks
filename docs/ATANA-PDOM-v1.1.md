# Atana Project Delivery Operating Model v1.1

Frozen baseline. Do not split PM and ISO 19650 into two systems.

## Rules
1. SA Stages 1–6 primary. RIBA is display mapping only.
2. DTL = Accountable. IM = Responsible for information management. PDM = Responsible for design delivery.
3. VP is commercial master. Atana only references VP startup evidence.
4. Roles preserved: DTL, PDM, IM, TTM, TTIM, IA.
5. Programme sequence is governance → packages → deliverables → reviews → gates.

## SA ↔ RIBA
| SA | RIBA |
|---|---|
| 1 Inception | 0–1 |
| 2 Concept & Viability | 2 |
| 3 Design Development | 3 |
| 4 Documentation & Procurement | 4 |
| 5 Construction | 5 |
| 6 Close Out | 6–7 |

## Layers
1. Governance tasks — DTL / PDM / IM
2. Production packages — task-team WBS
3. Deliverables — models, drawings, calculations, reports, specifications, schedules, registers, submissions
4. ZZ gates — project milestones, not a role

## Visibility
Active role editable. All other DTL/PDM/IM/TTM/TTIM tasks visible, grey, read-only.
