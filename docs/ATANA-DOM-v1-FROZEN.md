# Atana Delivery Operating Model v1.0 — FROZEN

Do not drift this architecture. Refine catalogues only.

## Frozen principles
1. SA stages 1–6 are primary. RIBA is a mapping layer (project setting: SA / RIBA / Both).
2. ISO 19650 is embedded in tasks. Not a second system. Default: Enabled.
3. VP remains the commercial master. Atana references VP (DTL.02.01 Complete VP Startup + evidence ticks). It does not replace VP.

## Accountability
- DTL = Accountable (A)
- IM = Responsible (R) for Information Management
- PDM = Responsible (R) for Design Delivery

## Visibility
Active role editable. DTL / PDM / IM / TTM / TTIM others grey, read-only, not completable.

## Hierarchy
Stage → Governance tasks → Production packages → Deliverables → Reviews → Approvals → Submission → ZZ gates

## Layers
- Governance: DTL.01–10
- Delivery: PDM.01–06
- Information: IM.01–08
- Production packages: task-team WBS (AR, CV roads/earthworks, ST, bridges, ME, HVAC, EE, PH, Fire, Controls, Security, Process, Landscape)
- Deliverables: models, drawings, calculations, specifications, reports, schedules, registers, submissions
- Gates ZZ-001 … ZZ-011 (milestones, not a role)

## Project settings
- Project Delivery Framework: South Africa / RIBA / Both
- Contract form: CESA / CIDB / FIDIC / NEC3 / NEC4 / PROCSA
- ISO 19650: Enabled (default) / Disabled
