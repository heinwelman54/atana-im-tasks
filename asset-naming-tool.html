Content Catalog process — single source of assets

The Content Catalog (UNIFI / Forma) is the only approved source of design assets. Project models consume published content; they are not the place to permanently fix or store company families.

Governance (BIM Champions & project teams)
  • Task Team BIM Champion owns the task-team collection (write access). Architecture, Mechanical, Structural, Electrical, etc. each curate their own library.
  • BIM Team / Information Management aligns standards (naming, shared parameters, classification) across collections and with project IMs.
  • Project TTM / TTIM / authors consume catalog content inside project space; they coordinate issues back to the champion — they do not become the long-term source of the family.
  • Fix path: asset leaves project space → champion repairs in a controlled library environment → update Content Catalog → notify project member(s) to load the latest.
  • Revit 2025 is the base version for catalog content. Forma/catalog auto-upgrade serves later Revit versions so users are not blocked by upgrade prompts when loading.

How-to guides

1. Name families in Revit
  • Build the name in this tool: Originator_Source_Category_Material_Object.
  • Default Source for Atana design content is STD (Standard). Use a manufacturer code only for true manufacturer content.
  • Copy the preview name and set it as the Family Name in the Revit family editor (not only the type name).
  • Put sizes, ratings, and variants on Family Types (this replaces NBS Differentiator).
  • Keep PascalCase / alphanumeric fields; underscore between fields only.
  • Example: ATA_STD_AIR_GEN_BoilerCondensing
2. Apply classification (PyRevit script)
  • After naming, run Atana_Asset_Classify_PyRevit.py in PyRevit (with asset-naming-data.json available).
  • The script parses the family name and writes Uniclass Ss / Ma / Pr and IFC4 to shared parameters.
  • Shared parameter GUIDs will be confirmed to match your ATA_ZZ_SharedParameters file (you will supply final GUIDs).
  • Target parameters (names): ATA_ZZ_UniclassSs, ATA_ZZ_UniclassMa, ATA_ZZ_UniclassPr, ATA_ZZ_IFC4.
  • Always verify values on the family before publishing to the catalog.
3. Publish to Forma Content Catalog
  • Only BIM Champions publish into their task-team collection (AR, ME, ST, EE, YS…).
  • Open Content Catalog → your collection → add / replace the family from the controlled library (not from a random project save).
  • Confirm naming, shared parameters, and Revit 2025 base save.
  • Notify the project TTM / authors that a new version is available so they reload from catalog (not from old project copies).
  • Catalog remains the system of record; project space only consumes.
4. Request missing content
  • In Content Catalog use Create content request.
  • Set collection (task team), file type (Revit), minimum year (2025), specifications, and priority.
  • Request routes to the task-team BIM Champion to create, name (this tool), classify, and publish.
  • Requester is notified when the asset is available in the collection for Revit / AutoCAD / Civil 3D as applicable.
